# 03. User Flow

## 서비스 전체 흐름

```text
회원가입
    │
    ▼
로그인
    │
    ▼
메인 페이지
    │
    ▼
면접 생성
    │
    ├── 이력서 선택
    ├── 채용공고 선택
    ├── 직무 선택
    └── 난이도 선택
    │
    ▼
AI 면접 생성
    │
    ▼
질문 조회
    │
    ▼
답변 입력
    │
    ▼
AI 꼬리 질문 (선택)
    │
    ▼
다음 질문
    │
    ▼
면접 종료
    │
    ▼
AI 평가
    │
    ▼
결과 리포트
    │
    ▼
마이페이지
    │
    ▼
면접 기록 조회
```

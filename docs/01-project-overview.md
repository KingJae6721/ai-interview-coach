# AI Interview Coach - Project Overview

## 1. 프로젝트 개요

### 프로젝트명

**AI Interview Coach**

### 한 줄 소개

채용공고와 이력서를 기반으로 실제 기업 스타일의 기술 면접을 진행하고, AI가 답변을 분석하여 맞춤형 피드백과 성장 리포트를 제공하는 면접 코칭 플랫폼.

---

## 2. 프로젝트 배경

기존 AI 면접 서비스는 단순히 GPT를 호출하여 일반적인 면접 질문을 생성하는 경우가 많다. 그러나 실제 기업 면접은 다음과 같은 요소를 기반으로 진행된다.

* 채용공고의 요구 기술
* 기업의 인재상
* 지원자의 이력서와 프로젝트 경험
* 답변에 대한 꼬리 질문
* 이전 면접 기록과 성장 추이

본 프로젝트는 이러한 실제 면접 프로세스를 서비스에 반영하여 **단순 질문 생성기가 아닌 AI 기반 면접 코치**를 만드는 것을 목표로 한다.

---

## 3. 프로젝트 목표

### 최종 목표

사용자가 실제 기업 면접과 유사한 환경에서 반복적으로 연습하고, 자신의 약점을 데이터 기반으로 개선할 수 있는 플랫폼 구축.

### 세부 목표

* 기업 맞춤형 면접 질문 생성
* 이력서 기반 프로젝트 질문 생성
* 답변에 대한 AI 평가 및 피드백 제공
* 면접 기록 저장 및 성장 리포트 제공
* RAG 기반 문맥 이해형 면접 시스템 구현

---

### 주요 사용자

* 주니어 개발자
* 이직 준비 중인 개발자
* 기술 면접 연습이 필요한 취업 준비생

* 기업별 맞춤 질문과 피드백을 원함

---

## 5. 핵심 문제 정의

### 현재 문제점

* 일반적인 면접 질문만 제공
* 기업별 차별화 부족
* 이력서 기반 질문 부재
* 답변에 대한 구체적인 피드백 부족
* 성장 추적 기능 부재

### 해결 방식

본 서비스는 **채용공고 + 이력서 + AI 분석 + 면접 기록**을 결합하여 개인 맞춤형 면접 경험을 제공한다.

---

## 6. 핵심 기능

### 1) AI 면접 생성

* 직무 선택
* 경력 선택
* 난이도 선택
* 기술 스택 입력

### 2) 채용공고 기반 분석

* 채용공고 URL 입력
* 요구 기술 자동 추출
* 기업 맞춤 질문 생성

### 3) 이력서 기반 질문

* PDF 업로드
* 프로젝트 경험 분석
* 프로젝트 심화 질문 생성

### 4) 꼬리 질문 시스템

* 답변 내용 기반 추가 질문 생성
* 실제 면접 흐름 재현

### 5) AI 답변 평가

* 논리성
* 기술 이해도
* 구체성
* 커뮤니케이션

### 6) 성장 리포트

* 면접 기록 저장
* 점수 추이 분석
* 약점 분석 및 추천 학습 제공

## 12. 프로젝트 성공 기준

다음 조건을 만족하면 MVP 성공으로 판단한다.

* 사용자가 회원가입 후 면접을 생성할 수 있다.
* AI가 직무 기반 질문을 생성할 수 있다.
* 사용자가 답변을 제출할 수 있다.
* AI가 답변에 대한 점수와 피드백을 제공할 수 있다.
* 면접 결과가 DB에 저장되고 다시 조회될 수 있다.
